# BlogSpace

A responsive blog application built with HTML, CSS and vanilla JavaScript.

## Features
- Responsive home page with category filtering and search
- Login and registration forms with client-side validation
- Dashboard with post counts
- Create, edit and delete blog posts
- Browser localStorage persistence

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Demo note
This is a front-end learning project. Authentication is demo-only and stores data in browser localStorage. Do not use real passwords or sensitive information. A production version requires a secure backend, password hashing, authorization and a database.
